# AQI Forecasting and Classification Using Machine Learning

## Project Overview
This project analyses hourly Air Quality Index (AQI) data for Chandigarh collected from CPCB datasets. It uses machine learning classification algorithms to predict the next recorded AQI category.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Models
1. Logistic Regression
2. K-Nearest Neighbors (KNN)
3. Gaussian Naive Bayes
4. Decision Tree
5. Support Vector Machine (SVM)

## Model Results

| Model | Accuracy |
|---|---:|
| Decision Tree | 95.33% |
| Logistic Regression | 92.91% |
| Gaussian Naive Bayes | 88.16% |
| SVM | 86.37% |
| KNN | 84.81% |

## Dataset
Hourly AQI data for Chandigarh, sourced from the Central Pollution Control Board (CPCB), January–September 2026.
